# v0.1.5

本版为正式版，迁移到 CPR 3.34，并在跟随账号换周时同时清零 Key 的日用量和周用量。

## 变更

- 清零范围由仅周用量改为日用量与周用量同步清零，使用宿主 `all` 重置，在同一事务中完成，仍只调用一次；结果未知不自动重试的规则不变。
- 关联详情新增 Key 今日用量，人工确认与待处理诊断显示重置前的日、周用量。
- 正式提醒邮件主题改为 `CPR Key 日、周额度已重置`，正文写明日额度和周额度已同步重置，时间固定为北京时间 UTC+8。
- 关联详情可手动发送测试消息或测试邮件，不清零、不更新周期基线。
- 页面所有时间固定按北京时间 UTC+8 显示，移除“显示时区”设置；旧设置值保留但不再生效。

## 兼容与升级

支持 CPR `>=3.34.0, <3.35.0`，SDK 与打包工具固定官方 v3.34.0（提交 `47d30474`，插件 RPC 7），构建工具链为 Rust 1.99.1。CPR 3.29.x 请继续使用 v0.1.4；3.30–3.33 无对应发行包。保留原插件身份与状态，无需卸载重装。

## 验证与限制

本地 Rust 格式、严格 Clippy、35 项后端测试，以及前端 lint、展示测试和生产构建通过。

提供 Linux x86_64、ARM64 安装包及 SHA-256 校验文件。ARM64 为交叉编译，未执行目标架构运行测试。

0.1.5-beta.4 已由使用者在 CPR 3.34 宿主本地上传安装并启用。账号真实换周触发的日周同步清零、自动模型请求与正式邮件投递尚未取得运行证据，升级后请观察第一次换周的结果。

## 改为 GitHub 更新

本地上传的版本没有远程更新来源。在已有插件详情选择“手动安装版本”→ GitHub，仓库填 `haohex/CPR-key-reset-follow`，标签留空、不勾选预发行版，保存来源并安装本版。之后可在插件详情“检查更新”。插件身份不变，关联与私有状态保留，不要卸载重装。
