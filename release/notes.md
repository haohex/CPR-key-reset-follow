# v0.2.0

本版起插件由 haohex 维护发布，插件 ID 改为 `haohex.key-reset-follow`。本仓库基于 [Ming-321/CPR-key-reset-follow](https://github.com/Ming-321/CPR-key-reset-follow) 二次修改，原作者的版权与 Apache-2.0 许可保持不变。

## 变更

- 发布者由 `ming321` 改为 `haohex`，清单新增作者说明；功能与 0.1.5 相同。
- 宿主将其视为新插件：不能在 `ming321.key-reset-follow` 上直接更新，旧插件的关联、设置与历史不会迁移。

## 迁移

1. 记下旧插件的关联、收件邮箱、开关与 SMTP 参数。
2. 先停用旧插件，避免两个插件对同一 Key 各清零一次。
3. 插件管理 → 安装插件 → GitHub，仓库填 `haohex/CPR-key-reset-follow`，标签留空，安装本版并启用。
4. 在设置中填写 SMTP 与开关，逐个添加关联并保存收件邮箱。新关联只记录当前周期，不补做清零。
5. 确认运行正常后再按需卸载旧插件；卸载会删除旧插件的私有数据。

之后在插件详情点击“检查更新”即可获取后续正式版。

## 兼容与验证

支持 CPR `>=3.34.0, <3.35.0`，SDK 与打包工具固定官方 v3.34.0（插件 RPC 7）。本地格式检查、严格 Clippy、35 项后端测试，前端 lint、类型检查、展示测试和生产构建通过；提供 Linux x86_64、ARM64 安装包及 SHA-256 校验文件，ARM64 为交叉编译未在目标架构运行。

新插件 ID 的安装与重新关联，以及真实换周触发的日、周同步清零和通知，尚未在真实宿主上验证。
