# v0.3.0

插件更名为"拼车一体化管理插件"，插件 ID 仍为 `haohex.key-reset-follow`。从 0.2.0 直接升级，原有关联、设置与历史保留。

## ⚠️ 升级后必须立即操作

本版起插件注册 HTTP 中间件以提供成员页。CPR 为新注册的 HTTP 挂载默认使用"拒绝"失败策略，插件清单无法修改；插件进程不可用时会拒绝**所有** API 请求。

1. 在低峰期升级并切换到本版
2. **立即**打开插件详情 → 高级设置，把 HTTP 挂载的失败处理改为 **委托**
3. 调用一次 API，确认请求正常
4. 打开 `https://你的网关域名/carpool/`，确认成员页可用

插件只接管 `/carpool` 与 `/carpool/*`，其他路径第一步就交还宿主。紧急处理：在高级设置关闭 HTTP 挂载，API 不再经过插件，周期清零与发卡照常运行，只有成员页不可用。

## 新功能

- **拼车成员页** `/carpool/`：成员输入自己的 Key 查看本周期起止、本人今日与本周用量、同车花费占比（他人名称打码、不显示金额）。Key 只保存在页面内存
- **日限重置卡**：每个关联可单独开启，跟随账号周期每周期发 1 张；成员在拼车页使用后清零当日用量，可选发送邮件通知。结果未知视为已用，由管理员核实后退还
- **本周期占比**：管理页显示每个 Key 本周期花费占账号花费的比例，统计每 10 分钟刷新
- **账号点数与上游重置卡**：管理页与成员页只读展示关联账号的额度点数、可用重置卡数量与到期时间。上游重置卡只在最近 30 分钟有人查看时查询，每账号 10 分钟最多一次；插件不会使用上游重置卡
- **页面改版**：管理页重新布局，详情分为概览、通知与测试、记录与诊断三个标签；UI 库升级到官方 v0.7.0

## 兼容与验证

支持 CPR `>=3.35.0, <3.36.0`，SDK 与打包工具固定官方 v3.35.0（插件 RPC 7）。CPR 3.34 请继续使用 v0.2.0。

本地格式检查、严格 Clippy、90 项后端测试，前端 lint、类型检查、17 项展示测试和生产构建通过；提供 Linux x86_64、ARM64 安装包及 SHA-256 校验文件，ARM64 为交叉编译。预发行版 0.3.0-beta.2（与本版功能相同）已由维护者在生产 CPR 3.35 上安装验证通过。
