# v0.1.4

本版为预发行测试版，新增周额度重置后的模型测试与 SMTP 邮件提醒，两个开关默认关闭。

## 新增功能

- 确认关联 Key 周额度清零成功后，可用该 Key 和关联账号向 `gpt-6.1-sol` 发送 `hello`，沿用默认思考强度，正常计费。
- 支持 SMTP TLS / STARTTLS、认证与发件地址设置，每个 Key 可独立设置收件邮箱。密码保存后不回显，可保留、替换或明确清除。
- 邮件包含 Key 名称、重置时间和测试结果；测试失败或结果未知仍可发送提醒。
- 测试与邮件分别记录发送状态，发送前持久化意图，未知结果不自动重试；管理员确认可能重复后可手动重试，不会重新清零。

## 兼容与升级

支持 CPR `>=3.29.0, <3.30.0`，SDK 与打包工具保持固定官方 v3.29.1。保留原插件身份与状态，升级后在设置中启用新功能，在关联详情填写收件邮箱，无需卸载重装。

## 验证与限制

本地 Rust 格式、严格 Clippy、29 项后端测试，以及前端 lint、2 项测试、类型检查和生产构建通过。明暗主题、窄屏和通知详情使用合成数据预览核对。

提供 Linux x86_64、ARM64 安装包及 SHA-256 校验文件。ARM64 为交叉编译，未执行目标架构运行测试。

真实 CPR 安装升级、状态保留、真实模型请求和 SMTP 邮件投递尚未联调，本预发行版供隔离环境测试。模型测试正常消耗额度；发送结果未知时，请核实后再手动重试。

维护任务每轮最多执行一次外发，模型测试最多等待 20 秒，邮件最多等待 8 秒。每关联最多保留 32 条发送记录、全插件最多 128 条；积压满时跳过本次新增通知并记录事件，额度重置继续完成。
