# v0.2.2

修复 v0.2.1 在 CPR 3.41 上管理页面无样式的问题（对话框透明、下拉框与文字重叠）。功能与 v0.2.0、v0.2.1 相同，不含拼车功能。

## 修复

- CPR 3.37 起宿主改为按页面 `<meta name="codex-proxy-ui-theme-prefix">` 声明的前缀注入主题变量，未声明时使用 `z`；插件页面使用的 UI 库读取 `--cp-*` 变量，因此全部样式变量缺失。页面现在声明前缀 `cp`，宿主传入的主题变量与明暗主题恢复生效

## 兼容与验证

支持 CPR `>=3.41.0, <3.42.0`，SDK 与打包工具固定官方 v3.41.0（插件 RPC 7）。本地格式检查、严格 Clippy、35 项后端测试，前端 lint、类型检查、展示测试和生产构建通过；按 CPR 3.41 宿主的主题注入方式（UI v0.8.0 主题变量、读取页面前缀）做了合成数据截图，确认明暗主题样式恢复。提供 Linux x86_64、ARM64 安装包及 SHA-256 校验文件，ARM64 为交叉编译。

从 v0.2.1 升级：插件详情检查更新，或安装时指定标签 `v0.2.2`，关联与设置保留。
