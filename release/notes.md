# v0.2.3

## 行为变更

- **账号正常换周时插件不再清零**：Key 的日、周预算窗口到期后会由 CPR 自行清零，插件只更新基线并记录一次事件，不调用清零，也不发送测试消息或邮件
- 上游提前重置或使用重置卡时，仍按原规则同时清零 Key 的日、周用量（自动或人工确认），并按设置发送测试与邮件
- 正常换周后新窗口未固定期间仍进入"等待周期固定"阶段，结束时间后移不会被误判为提前重置

## 兼容

- 宿主范围改为 `>=3.45.2`，**不再设置最高版本**；SDK 与打包工具固定官方 v3.45.2（插件 RPC 7）。CPR 3.41 请使用 v0.2.2
- 若以后 CPR 更换插件协议版本，宿主会拒绝加载本版，需要发布新版本

## 已知影响

- 插件不再在正常换周时对齐 Key 与账号的周窗口。Key 的周窗口从过期后首次使用起计 7 天，会与账号周窗口逐渐错开
- CPR 3.45 起管理员可为 Key 设置显式预算窗口，这类窗口不会自动滚动；对这类 Key，正常换周时插件同样不会清零

## 验证

本地格式检查、严格 Clippy、37 项后端测试（新增正常换周不清零、不发信，以及新窗口漂移不误判为提前重置），前端 lint、类型检查、展示测试和生产构建通过；提供 Linux x86_64、ARM64 安装包及 SHA-256 校验文件，ARM64 为交叉编译。尚未在真实 CPR 3.45.2 宿主上验证。

从 v0.2.2 升级：插件详情检查更新，或安装时版本标签留空 / 填 `v0.2.3`，关联与设置保留。
