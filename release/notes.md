# v0.2.1

不含拼车功能的维护版本，功能与 v0.2.0 相同，仅适配 CPR 3.41。插件 ID 仍为 `haohex.key-reset-follow`。

## 变更

- 宿主范围改为 `>=3.41.0, <3.42.0`，SDK 与打包工具固定官方 v3.41.0（插件 RPC 7）
- 不注册 HTTP 中间件，无成员页、日限重置卡、占比与账号点数展示；需要这些功能请使用 v0.3.x

## 安装与升级

- 从 v0.2.0 升级：插件详情检查更新或在安装时指定标签 `v0.2.1`，关联、设置与历史保留
- 从 v0.3.x 换回本版：关联、设置与历史保留；日限重置卡开关、周期序号与卡记录在本版首次保存状态时丢弃，之后再升级到 v0.3.x 需重新开启。成员页 `/carpool/` 不再可用

## 兼容与验证

本地格式检查、严格 Clippy、后端测试，前端 lint、类型检查、展示测试和生产构建通过；提供 Linux x86_64、ARM64 安装包及 SHA-256 校验文件，ARM64 为交叉编译。尚未在真实 CPR 3.41 宿主上安装验证。
